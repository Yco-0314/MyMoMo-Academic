请从本次实验中提取 **新的或需更新的** 知识条目。每条知识用以下 JSON 格式输出：

```json
[
  {
    "key": "简短唯一标识（英文下划线命名，如 high_infection_rate_threshold）",
    "knowledge": "用自然语言描述发现（中文）",
    "confidence": 0.0到1.0的置信度,
    "category": "pattern 或 rule 或 anomaly 或 hypothesis"
  }
]
```

### 类别说明
- **pattern**: 重复出现的规律（如"感染率>0.5 时系统进入爆发状态"）
- **rule**: 高置信度的因果关系（如"恢复率与最终感染人数成反比"）
- **anomaly**: 异常或意外发现（如"某参数组合导致震荡而非收敛"）
- **hypothesis**: 待验证的猜想（如"可能存在临界阈值在 0.3-0.4 之间"）

### 规则
- 只输出 JSON 数组，不要其他文本
- 如果没有新知识可提取，输出空数组 `[]`
- 如果已有知识库中某条需要更新（更高置信度或更精确的描述），用相同 key 输出新版本
- 每次最多提取 5 条知识
- 置信度参考：单次观察 0.3，多次重复 0.6，统计验证 0.8+
