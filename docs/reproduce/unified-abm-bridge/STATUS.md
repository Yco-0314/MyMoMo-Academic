# Unified ABM Bridge Contract Status

Phase 1 adds a public, machine-checkable bridge contract for the unified ABM
platform direction.

The seed contract is `example-contract.json`. It connects public MIR, GISABM,
NetLogo semantic migration, Evidence Foundry, transport, and a closed extension bridge
artifacts by path and boundary rule.

Boundary: this is not a unified runtime, not a NetLogo parser, not private backend
execution, and not a scientific truth certificate. It validates the public
artifact exchange contract only.
